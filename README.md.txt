# Stock Market Dashboard & Price Predictor

A real-time stock analysis dashboard with ML-powered next-day price prediction.

## Live Demo
https://stock-dashboard-nim4h834t5xfox2hi4ytve.streamlit.app/

## Features
- Real-time stock data for Indian (NSE) and US markets
- Candlestick chart with Bollinger Bands and Moving Averages
- RSI and MACD technical indicators
- Next-day price prediction using Linear Regression and Random Forest
- Model performance comparison (R² score, MAE)

## Tech Stack
Python · Pandas · NumPy · Scikit-learn · Plotly · Streamlit · yfinance

## Run Locally
pip install -r requirements.txt
streamlit run app.py
